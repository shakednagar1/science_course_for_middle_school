# מדע וטכנולוגיה – השלמת פערים (כיתות ז׳–ח׳)

קורס דיגיטלי בעברית ללמידה עצמית, לתלמידה שנכנסת לכיתה ט׳ ויודעת מדעים רק עד כיתה ו׳. הקורס בנוי לפי תוכנית הלימודים של משרד החינוך לכיתה ז׳, וברמה של מבחני המפמ״ר.

## איך פותחים

- **כאתר (מומלץ, עובד גם בטלפון):** ב־GitHub: Settings ← Pages ← Source: "Deploy from a branch", ובוחרים את הענף הראשי ותיקייה `/ (root)`. אחרי דקה הקורס זמין בכתובת `https://shakednagar1.github.io/science_course_for_middle_school/`.
- **מקומית:** פותחים את `index.html` בדפדפן. (הסרטונים צריכים אינטרנט.)

## איך הקורס עובד

- **7 שלבים בסדר קבוע** + שבוע חזרה ומבחן סיום, בתכנון ל־8 שבועות.
- **כל שיעור:** סרטון הסבר ← שקופיות עם הסבר ואיורים ← 4–6 שאלות בדיקה עם משוב מיידי. השיעור הבא נפתח אחרי שעונים על כל שאלות הבדיקה.
- **מבחן שלב:** נפתח אחרי כל השיעורים בשלב. ציון 80 ומעלה פותח את השלב הבא. בכל ניסיון מוגרלות שאלות אחרות מהמאגר, וכ־30% מהשאלות הן חזרה על שלבים קודמים.
- **התקדמות** נשמרת בדפדפן. כדי לעבור בין מחשב לטלפון מעתיקים את "קוד ההתקדמות" בתחתית מפת הקורס ומדביקים אותו במכשיר השני.

## מבנה הקבצים

- `index.html` – מפת הקורס, התקדמות וקוד התקדמות.
- `test.html?level=g7-1` – מבחן שלב (מגריל שאלות מ־`js/bank-g7.js`).
- `js/course-data.js` – רשימת השלבים והשיעורים. שיעור בלי `path` מופיע כ"בהכנה".
- `js/course.js` – נעילות, שקופיות, וידאו, שאלות בדיקה, קוד התקדמות.
- `g7/levelN/lessonM.html` – השיעורים. כל `<section class="slide">` היא שקופית; השקופית האחרונה היא שאלות הבדיקה.
- `g8/` – שיעורים של כיתה ח׳ (נפתחים אחרי מבחן הסיום של ז׳).

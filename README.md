# מדע וטכנולוגיה – חזרה על כיתות ז׳–ח׳

קורס בעברית לתלמידה שנכנסת לכיתה ט׳ בלי רקע במדעים. הקורס עובר על החומר של כיתות ז׳ ו־ח׳ לפי תוכנית הלימודים "מדע וטכנולוגיה לחטיבת הביניים", מההתחלה ובלי להניח ידע קודם.

## איך פותחים את הקורס

- **הכי פשוט:** מורידים את התיקייה ופותחים את `index.html` בדפדפן (לחיצה כפולה). לא צריך אינטרנט ולא צריך להתקין כלום.
- **כאתר באינטרנט (מומלץ, עובד גם בטלפון):** ב־GitHub נכנסים ל־Settings ← Pages, בוחרים Branch: `main` ותיקייה `/ (root)`, ושומרים. אחרי דקה הקורס יהיה זמין בכתובת `https://shakednagar1.github.io/science_course_for_middle_school/`.

ההתקדמות (אילו שיעורים סומנו כ"סיימתי") נשמרת בדפדפן שבו לומדים.

## מבנה כל שיעור

1. 🎯 מטרות – מה לומדים בשיעור.
2. הסבר עם דוגמאות מחיי היומיום, טבלאות ואיורים.
3. 💡 תיבות "שימי לב" – טעויות נפוצות ומלכודות.
4. 📝 סיכום קצר.
5. ✏️ תרגול – שאלות אמריקאיות עם משוב מיידי ושאלות פתוחות עם תשובה מלאה.

בסוף כל יחידה יש מבחן סיכום.

## למי שמוסיף תוכן

- רשימת היחידות והשיעורים נמצאת ב־`js/course-data.js`. שיעור שיש לו `path` מופיע כקישור; בלי `path` הוא מופיע כ"בקרוב".
- כל שיעור הוא קובץ HTML בתיקיית היחידה (`unit1/lesson1.html` וכו׳). הכי קל להעתיק שיעור קיים ולשנות את התוכן.
- שאלה אמריקאית: `<div class="q" data-correct="2">` (מספר התשובה הנכונה, מ־1), עם כפתורים בתוך `.options` והסבר בתוך `.explain`.
- שאלה פתוחה: `<div class="q">` עם `<details class="answer">` שבו התשובה.
